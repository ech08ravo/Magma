Upload Prepared SEBE Files

Use the files from the newest ready-to-upload SEBE folder generated by the updater script. Drag the files below in any order. The dashboard sniffs headers to identify each file. An optional Course Data.csv (or legacy course-titles.csv) adds course names. Legacy v2.x merged CSVs are also accepted.
