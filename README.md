# Magma: curriculum dashboard and curriculum map builder

| Folder | What it is | Use it for |
|---|---|---|
| `v8/` | **Dashboard v8.0 lite**: loads the .xlsx files each person downloads from CALM. No scripts. | Sharing with colleagues. Send `Curriculum-Dashboard-v8-lite.zip`. |
| `v8/Curriculum-Map-Builder/` | **Excel curriculum map builder** (macro workbook). Imports a dashboard timeline export (v7.4 or v8) and builds the Timeline, Weeks, AOL type balance, All tasks and Summary sheets. | Give colleagues `Curriculum Map Builder (blank).xlsm`. See `SETUP.md` for code updates. |
| `v7/` | **Dashboard v7.4 full**: the SEBE extraction and statistics scripts (`Extract SEBE.command` / `.bat`), unit guides and the dated `CALM-dashboard-YYYYMMDD` data folders. | Whole-of-SEBE work. `Curriculum-Dashboard-v7-full.zip` is the full kit. |
| `archive/` | Dashboards v0–v6, the Python curriculum map builders (v1, v2) and early experiments (`old/`). | Reference only. |

The `CALM-dashboard-*` folders and videos stay on this Mac. Git ignores them.
